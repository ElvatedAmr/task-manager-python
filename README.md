# Python Task & Calendar Management Application

Interactive task management application built for UMD's INST326 
(Object-Oriented Programming for Information Science).

## What this includes
- OOP-based task/calendar management logic
- Persistent data storage for tracking tasks
- Priority-based task organization

## Tech used
Python, Object-Oriented Programming, SQL

## Notes
Built as a coursework project; later iterated on through additional 
assignments in the same course.
